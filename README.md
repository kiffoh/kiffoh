# 👋 Hi, I'm Kiff

Full-stack software engineer at Accenture, working in TypeScript, Node.js, Java, React and AWS. I currently work on a multi-tenant file-conversion microservice (~1M requests a year), where I own the validation layer and API contracts. I replaced the incumbent converter and cut upload time by 97%.

I enjoy solving complex, real-world problems because I can see the difference the result makes to people's lives. I tend to dig into the details, whether that means understanding how a system works under the hood, investigating unexpected behaviour, or working out the right approach from technical documentation. I'm particularly interested in building reliable software, which I define as well-tested and monitored in production, because real users always find the cases the design didn't predict.

My route into software engineering was through Chemical Engineering. I graduated from the University of Manchester with an MEng (specialising in digital engineering) and initially worked as a safety engineer. That engineering background has carried into how I approach software: understanding problems systematically, paying attention to detail, and considering how systems behave beyond the happy path.
